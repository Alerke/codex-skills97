# 发布前正文准备

本发布技能不维护自己的视觉主题。正文排版统一交给 `$website-article-editorial-layout`；本文件只规定源内容归一化、交接和发布门禁。

## 固定流水线

1. **归一化内容**：从 DOCX、HTML、Markdown 或纯文本中恢复文章标题、章节、段落、列表、引用、链接、表格和图片位置。只整理结构，不改写事实、结论或语气。
2. **核对结构**：记录标题、章节数、图片数、表格数和外链数。标题通常交给发布接口，正文片段不重复 `<h1>`。
3. **交给官网排版技能**：读取 `$website-article-editorial-layout` 的入口、版式规范和配色库。用户指定配色时直接使用；未指定时运行该技能的 `scripts/select_palette.py --title "文章标题"`。批量文章用 `--avoid` 避免与上一篇重复。
4. **生成正文片段**：只输出 UTF-8 的 `<section>...</section>` 富文本片段，样式全部内联，不带文档外壳、脚本、预览按钮或平台工具栏。已经过用户确认且校验通过的成稿可以直接进入下一步，不强制重排。
5. **处理图片**：图片必须为公开可访问的 `https://` URL 或站内路径，并具有准确 `alt`。纯文字发布时删除图片及对应图片说明，不保留占位。
6. **双重门禁**：先运行官网排版技能的 `validate_fragment.py`，再运行本技能的 `validate_publish_html.py`。两个校验都通过后才允许查重与 POST。

## 内容保真抽查

- 标题与用户指定标题完全一致；
- 原文首段、任一中段和末段都能在排版结果中找到；
- 章节顺序、列表项数量、链接目标和表格行列没有变化；
- 图片数量、位置和处理结果符合用户选择；
- 自动生成的小标题不引入新事实或结论；
- 正文不存在重复标题、空分隔区、异常大空白或长裸链接。

## 官网富文本边界

可以保留：章节标题、导语、信息块、列表、引用、代码块、表格、公开图片、图片说明和原文已有的作者信息。

必须移除或禁止新增：

- 点赞、在看、转发、关注公众号、复制到公众号等互动或工具元素；
- 原文没有的作者签名、二维码、品牌口号和推广文案；
- 本地文件路径、Base64 图片、空图片地址和素材占位；
- `<script>`、`<style>`、表单、iframe、事件属性、JavaScript 链接、外部 CSS；
- 固定正文宽度、额外左右内边距和会导致移动端横向滚动的样式。

## 校验命令

```powershell
python "<website-article-editorial-layout>/scripts/validate_fragment.py" article.formatted.html
python scripts/validate_publish_html.py --html article.formatted.html
```

发布记录同时保存：文章标题、配色名称与 ID、正文文件哈希、图片数量和最终验收 URL。不得把 AccessKey Secret 写入任何记录。
