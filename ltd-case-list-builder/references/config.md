# 案例配置

完整基线见技能根目录 `案例列表配置.json`。

配置根项包括分类、多语言、分类/全部/搜索/封面/摘要/日期/推荐/分页开关、桌面列数、图片比例和基础颜色。

每项配置独立归一：

- 未替换占位符回退默认值。
- switch 显式识别 `1/0/true/false` 及字符串。
- number 转换后检查有限值并限制范围。
- color、ratio、URL 使用对应白名单或格式校验。
- category 各子字段独立回退。
- i18n 运行时对象异常时回退内置中文。

交付前收集所有 `$[root]` 和 `$[root.field]`：

1. 每个 root 在 JSON 中恰好一次。
2. 点号字段不生成独立 JSON 项。
3. `cat/i18n` 的 value 与 default_value 均可再次解析。
4. JSON 中没有无使用目的的配置项。
