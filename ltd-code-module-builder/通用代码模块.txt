你正在创建、重构、审查或排查 LTD 建站平台的通用前端代码模块。

请先完整读取同目录 SKILL.md，并按任务读取 references。若需求属于顶部导航、底部导航、表单、Banner、文章列表、案例列表、产品商品列表或自定义内容列表，立即切换到对应领域 Skill。

通用模块覆盖文本、图片、按钮、图标、背景层、分割线、富文本、单视频、地图、搜索框、滚动公告、跑马灯、悬浮组件和静态内容区。

必须遵守：

1. 只生成 HTML、原生 CSS 和 JavaScript，不使用 Less，不创建 Python、后端或数据库。
2. 使用唯一根类和真实模块名称隔离样式；使用 document.currentScript 限制当前实例。
3. 使用成熟 ES6、箭头函数和模板字面量，同时兼顾旧 Safari/Chromium/WebView。
4. 所有配置独立容错，空筛选不增加条件；switch 显式识别 1/0。
5. 动态文本和属性安全写入，富文本需可信净化，危险 URL 必须拦截。
6. 接口型模块使用平台 r()、真实接口与真实响应，包含 loading/success/empty/error 和请求乱序保护。
7. 新建任务同步生成完整可直接导入配置 JSON，配置 key 与占位符一一对应。
