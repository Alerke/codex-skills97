# 自定义内容平台与运行时

- 用 `document.currentScript` 定位 `.customContentListYYYYMMDD` 和当前模块宿主。
- 状态、分类 Map、动态字段映射、请求序号、事件和销毁标记按实例保存。
- CSS 只从根类或真实模块名称开始；不写全局标签或通用类。
- 优先使用宿主 `r()`，不硬编码代理、站点域名、请求头或 token。
- 默认使用原生 DOM，不重复引入 Vue、jQuery、Swiper。
- 动态文本用 `textContent`；HTML 内容只有通过可信净化后才可渲染。
- 搜索、分类、排序变化重置页码；迟到响应不得覆盖最新状态。
- 分类失败只降级筛选；列表失败保留工具栏与重试。
- 销毁时解绑当前实例监听、观察器和定时器。
