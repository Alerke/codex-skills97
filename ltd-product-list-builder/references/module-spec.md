# 产品与商品列表默认模块规格

## 1. 默认组成

默认模块包含：

1. 可选分类栏。
2. 可选搜索和排序工具栏。
3. 产品/商品通用卡片区域。
4. loading、empty、error 三种状态区。
5. 可选分页。

默认不包含 SKU、加购、收藏、比较、支付、登录拦截、复杂筛选抽屉或产品详情弹窗。

## 2. 工具栏

- 工具栏不存在可用控件时整块隐藏，不留空白占位。
- 搜索按钮与回车执行同一逻辑；清空搜索后恢复当前分类的第 1 页。
- 分类切换、排序切换和新搜索都重置到第 1 页。
- 排序至少可支持默认、最新、价格升序、价格降序，但只展示接口与设计允许的选项。
- 移动端允许工具栏换行，不用横向滚动隐藏核心控件。

分类区域按 [`category-tree.md`](category-tree.md) 实现：后台只选子分类时提升，父子同时选择时去重；选择父分类时查询父级及允许范围内全部后代，“全部”只清空语义选择而不突破后台范围。

后台 category 配置为空或未传时不限制分类，默认获取当前产品/商品适配器的全部数据，并保持“全部”状态；不自动选择首个分类。

`show_all_button` 控制“全部”选项是否显示，默认开启。关闭时分类项仍正常显示，空 `selectedCatId` 仍表示全部数据；不能为了隐藏“全部”而自动选中第一个分类。

## 3. 卡片

- 主图区域有稳定比例和空图降级。
- 标题是主信息，副标题、分类、价格、市场价、销量和浏览量均按配置或数据存在性显示。
- 模块标题由当前类型自动决定：product 使用 `product_title`，goods 使用 `goods_title`；切换类型和适配器时同步更新可见标题与根节点无障碍名称。
- 销售价和市场价使用同一价格格式化器；最终 `priceText` 已含单位，默认各使用唯一文本节点。模板不得包含静态货币 span，CSS 不得通过伪元素添加货币符号。
- 通用卡片只消费归一化模型；商品库存/SKU/交易能力和产品摘要/参数/附件能力按适配器与用户配置显示。
- 整卡点击与内部链接不得嵌套 `<a>`。
- 详情 URL 未确认时不制造假链接；卡片可保持非链接状态。
- 有效点击卡片提供克制的 hover、清晰的 `focus-visible` 和按下状态；无操作卡片不显示手型或悬浮反馈。具体规则见 [`click-action-style.md`](click-action-style.md)。
- 静态点击配置按 [`click-action-type.md`](click-action-type.md) 使用点号字段；复杂类型复用平台 `data-gw-jump-*` / `data-gw-popup-*` 运行时，边界见 [`click-action-runtime.md`](click-action-runtime.md)。
- 图片懒加载，首屏是否 eager 由模块位置和性能要求决定。
- 搜索、清空、布局、分页和展开图标优先使用内联 SVG；使用 Font Awesome 时复用宿主已有版本，并为图标按钮保留可访问名称与加载失败回退。

## 4. 状态

- 初始：显示轻量骨架或加载提示，不展示“暂无数据”。
- 加载：保留工具栏状态，列表区域标记 `aria-busy="true"`。
- 成功：一次性切换为新列表和真实分页。
- 空数据：显示说明与重置筛选按钮。
- 错误：显示可读错误与重试按钮；不要暴露堆栈、令牌或原始响应。
- 后续分页加载时可保留旧列表并显示局部 loading，避免内容突然消失。

## 5. 分页

- 提供上一页、有限页码窗口和下一页。
- 当前页使用 `aria-current="page"`，不可用按钮设置 `disabled`。
- 总页数为 1 时默认隐藏分页。
- 点击页码只更新当前实例，成功后把焦点或滚动位置恢复到模块的合适位置。
- 如果用户明确要求“加载更多”，用独立按钮替代页码，不同时保留两套主分页。

## 6. 验收场景

至少检查：

- 同一套列表内核分别通过 product 和 goods 适配器运行。
- product 与 goods 各自使用正确接口、专属参数和专属字段。
- 分类为空、单分类、树形多分类。
- 0 条、1 条、整页、最后一页和接口报错。
- 快速连续切换搜索、分类、排序时没有旧请求覆盖。
- 无图片、超长标题、无副标题、无价格格式、价格为 0。
- 已确认 `data.data` 响应可得到 3 条数据、`total=3`、字符串 `page_size='12'` 归一为 12、`current_page=1`。
- `thumbnail.id=0` 但 URL 有效时仍显示缺省图；`defined_link=null` 时安全回退 `detail_url`。
- `price='120.00'` 按元显示，`price_ceiling='0.00'` 不显示为灰色划线市场价，空 `new_price` 不覆盖销售价。
- `¥100 + price_icon=¥`、`￥￥100`、`100元`、不同币种前缀等场景均只显示一个货币标识。
- 危险链接、`_blank` rel、图片加载失败；小程序受控 `jumpMall` 不被误删，也不放行接口脚本链接。
- 内联 SVG 的 `viewBox/currentColor/aria-hidden` 正确；Font Awesome 没有重复引入或版本混用，图标加载失败不影响按钮识别和操作。
- `none`、普通跳转、小程序、模块跳转、打开表单及 `form/qrcode/page/html` 弹窗语义正确且不会双重触发，卡片内部按钮不会误触整卡跳转。
- 320px 手机、768px 平板、1024px 和常规 PC。
- 同页两个模块拥有不同分类与分页状态。
- `cat_id.moduleType` 自动选择适配器；product/goods 切换时分类和列表接口成对切换，没有残留固定接口。
- 只选子分类、父子同时选择、父级递归包含所有层级后代以及展开后的“全部允许范围”语义正确。
- product/goods 切换后标题、多语言文案和根节点 `aria-label` 与适配器类型一致。
- `show_all_button=1/0` 分别显示/隐藏“全部”按钮；两种情况下空分类的请求范围完全一致，关闭后没有自动选择首项。
- category 配置缺失、ids 为空和未选择分类时均获取当前适配器全部数据，且没有自动选择首个分类。
- URL 参数按实例隔离；快速连续操作只让最后一次请求更新结果。
- 后台变量未替换、旧多语言字符串解析失败、语言或单个文案缺失时仍有可读降级；标准 `$[i18n]` 对象不被重复解析。
- 分别破坏 category、i18n、jump、switch、number 和样式配置时，当前实例仍以安全默认值运行；无效 `moduleType` 只显示局部配置错误。
