# 设计演变矩阵

每次从四个维度各选一个方向。需要多版本时，至少改变两个维度，避免只换色。

## 1. 布局原型

| 原型 | 适合内容 | 构图特征 |
|---|---|---|
| 3D 英雄物体 + 信息舱 | 一个主题、多个要点 | 上部或中部建立主物体，信息模块围绕或排列在下方 |
| 轨道系统 | 多个并列指标、生态或关系 | 指标沿环形或椭圆轨道分布，中心保留主命题 |
| 层叠卡片 | 步骤、优先级、前后关系 | 模块沿纵深层叠，利用遮挡和阴影表达顺序 |
| 非对称编辑分栏 | 标题较强、正文中等 | 大标题和 3D 视觉占一侧，信息以窄栏或编号排列 |
| 3D 字体雕塑 | 文案很短、传播优先 | 标题本身成为主视觉，说明文字极少 |
| 模块画廊 | 产品、功能或分类清单 | 大小不等的 Bento 模块，而非固定等宽九宫格 |
| 路径叙事 | 流程、方法、成长阶段 | 彩色路径或透明管线串联关键节点 |
| 数据核心 | 指标、诊断、报告摘要 | 中心数据仪表或诊断对象，外围使用少量标注和卡片 |

## 2. 材质家族

- **珍珠陶瓷 + 虹彩玻璃**：稳重、精密，适合咨询、科技、企业服务。
- **磨砂亚克力 + 柔和彩色透明件**：轻盈、现代，适合教育、创意工具和生活方式。
- **软质充气塑料 + 细腻织物**：亲和、年轻，适合消费品牌和活动宣传。
- **白色纸雕 + 局部金属**：编辑感强，适合文化、知识和出版主题。
- **透明凝胶 + 珍珠金属**：前卫、流动，适合创新、AI、未来体验。
- **哑光石膏 + 彩色光带**：克制、建筑感，适合专业服务与高端产品。

一次优先使用一个主材质和一个辅材质。材质过多会削弱极简感。

## 3. 辅助配色

- **光谱虹彩**：青、蓝、紫、洋红、橙少量连续过渡；适合综合主题。
- **青绿 + 钴蓝**：理性、技术、清洁；适合数据与平台。
- **紫罗兰 + 珊瑚橙**：创意、传播、活力；适合营销和活动。
- **酸橙 + 湖蓝**：年轻、效率、增长；适合工具和运营。
- **玫红 + 金橙**：醒目、社交、消费；适合节庆或促销。
- **单色强调**：只用一种品牌色及其明度变化；适合严肃或强品牌约束。

白色背景占 70%–90%；彩色通常占 10%–25%；正文使用石墨黑或深灰。

## 4. 信息密度

- **封面型**：标题 + 一句副标题 + 1 个 3D 焦点 + 3–5 个关键词。
- **平衡型**：标题 + 3D 焦点 + 5–9 个短信息模块。
- **信息图型**：标题 + 6–12 个模块，每个模块一行标题和一行短说明。
- **长文摘要型**：先将原文压缩为 3–5 个一级组，再在组内列要点；不要把段落直接塞进窄卡片。

## 组合建议

- 企业诊断：数据核心 + 珍珠陶瓷/虹彩玻璃 + 光谱虹彩 + 信息图型。
- 活动发布：3D 字体雕塑 + 软质塑料 + 紫橙渐变 + 封面型。
- 产品功能：模块画廊 + 磨砂亚克力 + 青蓝配色 + 平衡型。
- 方法流程：路径叙事 + 透明凝胶 + 青绿/钴蓝 + 信息图型。
- 高端咨询：非对称编辑分栏 + 纸雕/金属 + 单色强调 + 平衡型。

这些是起点，不是模板。内容结构、品牌限制和目标渠道优先。
