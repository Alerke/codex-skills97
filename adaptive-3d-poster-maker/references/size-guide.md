# 海报尺寸与安全区

优先遵循用户给出的像素、毫米或宽高比。只有用途明确但尺寸缺失时才使用下表。

| 用途 | 推荐比例 | 常用像素示例 | 版式提醒 |
|---|---:|---:|---|
| 手机全屏、短视频封面、Story | 9:16 | 1080×1920 / 2160×3840 | 标题避开顶部 8%，CTA 避开底部 10% |
| 社交媒体竖图 | 4:5 | 1080×1350 | 主视觉居中，底部不放过细文字 |
| 知识卡片、长图首屏 | 3:4 | 1080×1440 | 适合较多信息，保持左右 6% 安全区 |
| 方形帖子 | 1:1 | 1080×1080 | 减少模块数量，避免纵向堆叠过密 |
| 横版封面或演示屏 | 16:9 | 1920×1080 / 3840×2160 | 标题与主视觉可采用左右分栏 |
| 宽幅网站 Banner | 2:1 或 3:1 | 2400×1200 / 2400×800 | 保留可裁切负空间，避免关键信息贴边 |
| A4 印刷 | 1:1.414 | 2480×3508（300 dpi） | 先确认出血和印刷色彩要求 |
| A3 印刷 | 1:1.414 | 3508×4961（300 dpi） | 小字和细线需按实际印刷尺寸检查 |

像素仅为常用示例；平台规范或用户给定尺寸优先。

## 选择规则

1. 先判断观看环境：手机全屏、信息流、方形卡片、横向屏幕或印刷。
2. 再判断信息密度：内容越多，越需要更高的纵向空间或更少的一级模块。
3. 生成提示词中同时写明比例、用途和安全区，不只写“竖版”或“横版”。
4. 工具只保证近似比例时，生成后检查实际像素，再做无拉伸适配。

## 精确画布适配

使用 `scripts/fit_canvas.py`：

```powershell
python scripts/fit_canvas.py input.png output.png --width 1080 --height 1920 --mode cover
```

- `cover`：填满画布并裁切边缘，适合背景有足够留白的成品。
- `contain`：完整保留图像并补白，适合不能裁切文字或主体的成品。
- `--anchor top|center|bottom` 控制 `cover` 的纵向裁切重心。
- `--background "#FFFFFF"` 设置 `contain` 的补白颜色。

适配后必须重新检查标题、CTA、正文和 3D 主体是否被裁切或离边缘过近。
