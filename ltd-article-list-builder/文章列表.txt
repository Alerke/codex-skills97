LTD 文章列表模块生成 Skill

请使用以下规则创建、重构或审查 LTD 建站平台的文章列表模块，并同步输出完整 HTML 与可直接导入的配置 JSON。

一、职责边界

1. 只处理文章列表，不混入产品、商品、价格、SKU、库存、加购或交易逻辑。
2. 分类配置固定使用 moduleType: "article"。
3. 文章细分类型使用 cat.type，并映射到接口参数 mold_types。
4. 新建模块默认交付：
   - 原生首屏 CSS
   - 原生业务 CSS
   - 当前模块 HTML
   - 普通 script 中可运行的 JavaScript
   - 覆盖所有占位符的完整配置 JSON 数组

二、文章类型

已知类型：

- 1：文章
- 2：视频
- 12：图册
- 19：图文
- 11：公告通知
- 10：最新活动
- 6：常见问题
- 5：业务知识
- 7：官方招聘
- 8：媒体报道

分类和列表请求必须使用同一个 mold_types。不要把 article_1、article_7 等写成 moduleType；moduleType 始终是 article。

三、分类配置

分类根 key 默认使用 cat，input_type 固定为 category。

运行时读取：

- $[cat]
- $[cat.moduleType]
- $[cat.type]
- $[cat.pageSize]
- $[cat.sortColumn]
- $[cat.sortDirection]

$[cat] 已经是逗号分隔的分类 ID，不要执行 JSON.parse。

cat 的默认导入结构：

{"moduleType":"article","type":"1","ids":"","names":[],"pageSize":12,"sortColumn":"published_at","sortDirection":"desc","sortColumnVersion":2}

分类为空、没有传或 ids 为空时，表示获取当前文章 type 下全部数据，不要自动选择第一个分类。

如果配置了允许分类范围：

1. 递归读取分类树。
2. 父分类范围包含父级自身和所有层级后代。
3. 选择父级时，请求参数包含父级和全部后代 ID。
4. “全部”只表示允许范围内全部分类。
5. show_all_button 只控制“全部”按钮是否显示，不能改变查询语义。

四、接口

默认接口：

- 分类：/api/gatewayCms/articles/category
- 列表：/api/gatewayCms/articles/list
- 详情：/api/gatewayCms/articles/item/{id}

列表常用参数：

- mold_types
- cat_ids
- page
- page_size
- keywords
- sort_by
- sort
- language_type

优先使用页面已有 r() 请求封装。不要生成 localhost 代理、测试网站域名、tg-url 或固定 token。

分类配置为空时省略 cat_ids。排序字段默认 published_at，可使用 sort、views、created_at、updated_at 或通过合法格式校验的自定义字段。排序方向只允许 asc 或 desc。

五、响应

已确认列表主结构：

{
  "code": 0,
  "data": {
    "data": [],
    "total": 0,
    "page_size": 12,
    "current_page": 1
  }
}

已确认的列表项字段：

- id
- cat_id
- type
- title
- thumbnail
- source
- source_url
- author
- abstract
- seo_title
- seo_keywords
- seo_description
- sort
- is_recommended
- created_at
- updated_at
- website_id
- language_type
- published_at
- file
- original_application
- mold
- share_copy
- is_person
- status
- user_id
- block_id
- open_comment
- ai_status
- original_url
- content
- info.extension_field
- views

其中 id 的真实示例是字符串 "5742874609370519"。该示例当前仍在 JavaScript 安全整数范围内，但接口已经明确把 id 作为字符串返回。id 必须从头到尾保持字符串，禁止无意义的 Number(id)、parseInt(id)、+id 或数值运算，以兼容前导零、未来更大 ID 和后端字符串标识语义。

thumbnail 和 file 都是媒体对象，包含 id、is_image、width、height、duration、url、thumbnail、vod_video_id。封面按 thumbnail.url、thumbnail.thumbnail、file.url、file.thumbnail 回退。媒体 id 或 is_image 为 0 时，只要 URL 有效仍可显示。

cat_id 是文章所属分类 ID。返回项没有分类名称时，通过已请求的分类树 Map 查询；不要虚构 article_cat。

扩展字段的真实路径是 info.extension_field，值可能为 null。仅在兼容已确认的旧项目时，才把 article_info.extension_field 作为次级回退。

content 是完整 HTML 正文，可能非常长。默认文章卡片只使用 abstract，禁止把 content 未经净化直接插入 innerHTML。用户明确要求正文预览时，必须使用平台可信净化器或经过验证的净化流程，并限制最终文本长度。

source_url 和 original_url 是来源链接，不是本站文章详情链接。当前列表项没有 defined_link 或 detail_url，默认详情链接固定由完整字符串 id 生成：

/article/${encodeURIComponent(String(id))}

id 为空时渲染不可点击卡片。拒绝任意 javascript:、data: 和 vbscript:。

六、状态和交互

至少实现：

- 加载
- 成功
- 空数据
- 错误与重试

搜索、分类和排序变化时重置到第 1 页。使用请求序号或取消旧请求，保证最后一次操作的响应生效。分类接口失败不能阻塞文章列表。

分页数据来自真实 total、page_size 和 current_page，不能硬编码。分页按钮使用真实 button，并提供 disabled 和 aria-current。

七、多语言

多语言根 key 和 input_type 都固定为 i18n。

运行时 $[i18n] 是 JavaScript 对象，不要重复 JSON.parse。

语言优先级：

1. URL editor_language_type
2. localStorage.lang
3. zh-cn

标准语言 key：

- zh-cn
- zh
- en
- kr
- ru
- jp

当前语言缺少某个文案时，逐键回退到 zh-cn，再回退模块内置中文。请求的 language_type 与界面语言保持一致。

八、样式和实例

1. 只使用原生 CSS，不使用 Less。
2. 根类使用 .articleListYYYYMMDD。
3. 所有业务样式从根类开始，平台样式从真实模块名称或当前实例宿主开始。
4. 不裸写 html、body、:root、通用标签、.container、.wrapper。
5. 使用 document.currentScript 定位当前实例。
6. 所有 DOM 查询、事件、状态和请求序号限制在当前实例内。
7. 不使用固定 id、getElementById 或全局重复绑定。
8. 图标优先使用内联 SVG 和 currentColor；大量图标才复用页面已有 Font Awesome。

九、JavaScript

1. 使用普通 script 可直接运行的成熟 ES6。
2. 使用 const、let、箭头函数、数组迭代、解构、默认参数和模板字面量。
3. 多行 HTML 优先使用模板字面量，但动态文本、属性和 URL 必须先转义或校验。
4. 未确认环境时避免可选链、空值合并、async/await、动态 import、对象展开等更高版本能力。
5. 不依赖 :has()、:scope、replaceChildren()、Array.prototype.flat()、Object.fromEntries()。

十、配置容错

所有配置都是不可信输入：

- 未替换占位符回退默认值。
- 错误 JSON 只影响当前配置项。
- switch 显式识别 1/0、true/false 及对应字符串。
- 数字必须是有限值并限制范围。
- 分类各子字段独立回退。
- 多语言异常时回退内置中文。
- 任一配置错误都不能抛出未捕获异常或阻塞同页其他模块。

默认提供：

配置 JSON 顶层必须是数组。每项必须包含 key、label、value、default_value、input_type。cat 和 i18n 的 value/default_value 必须是可再次 JSON.parse 的字符串。

十二、验收

- moduleType 与 type/mold_types 没有混淆。
- 分类和列表的数据类型一致。
- 空分类获取当前 type 全量数据。
- 父分类包含全部后代。
- show_all_button 只影响显示。
- 列表响应和分页安全归一化。
- 长字符串 id 没有被数值化，详情路径保留接口返回的完整 id。
- cat_id 通过分类树解析，thumbnail/file 按 URL 正确回退。
- info.extension_field 为空时不报错，content 未经净化不会进入列表 DOM。
- source_url 和 original_url 没有误当成文章详情链接。
- 文章字段缺失时不报错。
- 详情链接与动态文本安全。
- 加载、空、错误、重试和分页完整。
- HTML 与可直接导入 JSON 同步交付。
- 原生 CSS、成熟 ES6、模板字面量、多实例和兼容性满足要求。
