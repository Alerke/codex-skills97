# LTD 列表模块提示词（防重复故障版）

请参考附件 UI，为 LTD 平台制作“新闻与文章”列表模块，并输出完整 HTML 与可直接导入的 JSON。

- 数据：`moduleType=article`，`type/mold_types=1`；展示封面、分类、标题、发布时间。
- 功能：后台可设置行数、列数、分类、排序、语言、分类筛选、搜索和分页；行数×列数作为每页数量。
- 分类：分类为空时查询当前网站全部新闻；选择父分类时包含其全部子分类；分类接口和列表接口使用相同 `website_id`、语言及类型。
- 站点 ID：禁止写死。每次请求前按 URL/iframe referrer、`window/parent/top` 全局变量、`localStorage.websiteId/website_id` 读取；等待平台延迟注入后再请求。
- 双端请求：编辑器 iframe 使用可用的 `r()`；前端使用同源 `fetch`，并提供 `XMLHttpRequest` 降级；保持 iframe 隔离开启也必须显示真实接口数据。
- 链接：详情只使用接口的 `pc_detail_link`；为空时用非链接元素，禁止拼接或推测地址。
- 样式：根 class、keyframes 和实例状态必须使用全站唯一命名，输出前扫描目标页面/现有模块，禁止与其他代码模块重复；所有 CSS 必须限定在本模块根节点下。
- 间距：提供 `padding_top` 和 `mobile_padding_top` 配置，默认分别为 64px、42px。
- 一致性：静态示例默认关闭；编辑器和已发布前端必须调用同一真实接口，使用同一分类、排序、语言和页大小。
- 多实例：脚本只能定位当前模块根节点，不使用固定 ID，不操作其他实例，并防止同一实例重复挂载。
- 验收：校验 JS 语法、JSON、全部 `$[...]` 占位符、接口字段映射；分别检查编辑器和实际前端 URL，确认根节点各存在且渲染真实文章后再交付。若前端根节点不存在，明确提示重新导入、保存并发布，不能误判为接口故障。
