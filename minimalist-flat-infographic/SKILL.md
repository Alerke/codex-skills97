# 极简扁平化信息图

## 调用边界

- 仅在用户明确指定调用本 Skill 时执行。普通生图需求、相似风格描述、其他 Skill 的生图流程都不构成调用授权。
- 本 Skill 定义本次指定图片的视觉规范，不把该风格设为其他图片或后续任务的默认风格。
- 用户只要求创建或修改本 Skill 时，仅处理技能文件，不生成图片。

## 视觉规范

- 采用 Minimalist Flat Infographic 风格，结合现代 SaaS UI、模块化卡片设计（Modular Card UI）与业务逻辑架构图（Business Flow Diagram）。
- 纯白背景，大面积留白，整体清爽、专业、现代。
- 使用二维扁平矢量图形，以圆角矩形作为主要信息容器。矢量级质感指视觉效果，不把位图宣称为可编辑矢量文件。
- 使用低饱和度浅蓝、浅紫、浅绿、浅灰作为模块背景；文字使用高对比度蓝色及深黑色。可参考浅蓝 #EFF6FF、浅紫 #F3F0FF、浅绿 #EDF8F1、浅灰 #F5F6F8、主题蓝 #2563EB、深黑 #111827。
- 不同业务模块用不同色块区分，同类模块保持一致。核心模块可用主题色描边突出。
- 采用规范网格；模块对齐、间距统一、大小协调。根据业务关系选择从左到右或从上到下的主阅读方向。
- 使用统一线宽、箭头头型和颜色表达业务流向及逻辑关系，明确连接起点、终点与方向；避免穿过文字和不必要的交叉。不得为了装饰增加无业务含义的连线。
- 字体使用现代无衬线中文字体，如思源黑体或 Noto Sans CJK SC；标题加粗，正文清晰。用字号、字重、位置与留白建立层级。
- 所有文字必须准确、完整、清晰可读。内容较多时优先精简措辞、合并重复表达，不通过缩小字体强行容纳；保留必要业务含义、专有名词、数字与条件，不捏造数据或关系。

## 禁止元素

不出现 3D 立体插画、卡通人物、拟物化设备、复杂渐变、玻璃反光、发光特效、厚重阴影、装饰性背景、科技光效、无意义图标或冗余视觉元素。通过布局、色块、细描边和留白建立层级，不依赖立体装饰。

## 内容与生成流程

1. 从用户材料中提取标题、业务模块、关键内容、流程方向与关系。没有内容且无法从上下文取得时，询问主题或待呈现资料，不生成虚构的业务架构。
2. 先确定准确的上图文案与结构，再排版。按内容选择流程、分层架构或分组卡片，不强行增加卡片数量或无依据的闭环。仅在关系存在实质歧义时询问用户。
3. 生图提示词须包含最终中文文案、模块层级、箭头关系、上述视觉规范、禁止元素及输出规格。使用当前可用的图像生成或编辑工具，提供必要参考图；不只返回提示词来替代用户要求的成图。
4. 检查生成结果：逐项核对文字、数字、模块完整性、箭头方向、留白、对齐、配色与禁止元素。错字、漏字、不可读文本或错误业务关系须修正后交付。
5. 检查实际画布尺寸。若工具无法直接输出目标尺寸，按可用工具规范进行合规的后续尺寸处理，并复核文字清晰度；不能完成时明确说明实际尺寸与限制，不能将提示词中的分辨率当作实际输出结果。

## 输出规格

- 默认采用 16:9 横版构图，目标分辨率 **3840×2160**。
- 高清文字，矢量级视觉质感，适用于企业官网、客户案例文章、产品介绍及商业演示。
- 默认交付 PNG 成图；用户明确要求其他格式或规格时遵循其当次要求。
- 展示最终图片并提供可用文件链接；说明实际尺寸。仅在确有交付限制时补充说明，避免冗长解释。
