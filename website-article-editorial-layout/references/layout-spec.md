# 官网文章排版规范

## 适用边界

本规范复刻的是已验收文章的正文编辑风格，不是整个详情页 UI。作者栏、二维码、咨询浮窗、底部关注与点赞栏、表单、热门文章和“阅读全文”属于平台外壳，不写入文章正文 HTML。

## 已验收的版式基线

以下数值来自 2026-08-21 对参考页桌面端与 390px 手机视口的检查，并结合实际发布后的修正：

| 项目 | 桌面端 | 手机端 |
| --- | ---: | ---: |
| 正文宿主可视宽度 | 由详情页模板决定 | 页面左右保留宿主间距 |
| 正文字号 / 行高 | 17px / 1.9 | 相同 |
| 正文章节标题 | 40px / 1.3 | 24px / 1.3 |
| 章节编号 | 14px / 1.5 / 700 | 相同 |
| 图片 | 正文宽度 100%，高度自动 | 相同 |

正文根节点使用白底、`Arial,'PingFang SC','Microsoft YaHei',sans-serif`、17px、1.9 行高和两端对齐。章节标题用 `clamp(24px,3.6vw,40px)` 在窄屏降到 24px。

## 色彩令牌

排版必须先选定 [color-palettes.md](color-palettes.md) 中的一套方案，准确值从 [color-palettes.json](color-palettes.json) 读取。组件只引用语义角色，不写死某套方案：

- `body`：正文主文字；
- `secondary`：次级正文；
- `heading`：导语、章节和来源标题；
- `emphasis`：链接、结论和强调线；
- `accent`：章节编号；
- `label` / `url`：辅助信息；
- `border` / `strong_border`：普通和强调分隔线；
- `cta`：主按钮；
- `background` / `soft`：基础和柔和背景。

同一篇文章只使用一套令牌。不要跨方案挑颜色，也不要因换色改变组件结构。

## 组件规则

### 正文根节点

根 `section` 必须是块级、相对定位、100% 宽度、最大宽度 100%、无内外边距、隐藏横向溢出并使用 `box-sizing:border-box`。正文片段不得固定 677px 或其他像素宽度；阅读宽度由详情页宿主控制。

### 导语区

- 用户已反馈文章开头不应出现过多空白，因此默认 `padding:0`；只有用户明确需要封面式留白时才增加上边距。
- 首段使用 `heading`、17px、600 字重、1.9 行高。
- 后续导语距上一段 12px，使用 `secondary`。
- 导语后接主视觉图时不加额外圆角或阴影。

### 图片与图注

- 默认自动为输入中的每张可发布正文图片生成图注；用户无需另行逐条提供。先结合图片本身、相邻段落和图片在文章中的作用确定说明，再生成图注。
- 每张正文配图必须与图注组成独立图片组，优先使用 `figure > img + figcaption`，一张图片对应一个非空图注。
- 图片组：`margin:18px 0 24px;padding:0`，不增加左右内边距、阴影或装饰边框。
- 图片：`display:block;width:100%;max-width:100%;height:auto;margin:0;padding:0;border:0;box-sizing:border-box`。
- 图注：`margin:8px 0 0;padding:0;color:label;font-size:14px;line-height:1.7;text-align:center`。
- 图注格式统一为“图 N｜简洁说明”，按图片在正文中的出现顺序从 1 开始连续编号，不重复、不跳号。
- `alt` 用于描述图片本身，图注用于说明图片与当前步骤或观点的关系；两者可以表达相近含义，但不得使用“图片”“截图”等无信息量文字。
- 输入能够确认图片性质时，图注可写“真实后台截图”“模拟对话示意图”或真实来源；无法确认时只写可验证的画面内容，不猜测来源。
- 外部图片只有在输入提供真实来源时才追加“来源：名称”；不要根据域名、文件名或画面猜测版权归属。
- 图片与前后段落保持 18px 左右的阅读节奏，避免额外空段、空容器或连续分隔线。
- 图片后的文字区块不另加左右内边距，保持与正文齐边。

### 关键短语强调

- 默认从关键段落中识别核心概念、关键时间或数据、验证结果、能力差异和业务价值，只强调有助于读者快速理解文章主线的短语。
- 概念、结果与价值使用当前配色的 `emphasis`；时间、版本或数据节点可使用同一配色的 `accent`。不得引入选定方案之外的新颜色。
- 使用 `<strong style="color:emphasis;font-weight:700;">短语</strong>` 或对应的 `accent` 颜色；关键样式必须写在元素 `style` 属性中。
- 一般每个关键段落突出 1—2 个短语，普通过渡段可以不标注。优先短语级标注，不把整句、整段或连续多段全部加粗变色。
- 不因强调而改写事实、扩大结论或新增判断；不默认强调企业名称、普通修饰语、来源链接和参考文献条目。
- 同一短语重复出现时，只在首次定义、关键转折或结论位置选择性强调，避免机械重复。

### 编号章节

- 章节容器：`padding:42px 0`，底部使用 `border` 分隔线。
- 编号：`accent`、14px、700、字距 1px、下边距 10px。
- 标题：`heading`、24px 回退 + `clamp(24px,3.6vw,40px)`、700、1.3 行高、下边距 26px。
- 正文首段无上边距，后续段落 18px 上边距。
- 小引导标题可用 17px、700，并在上方留 30px、下方 14px。
- 列表使用内置圆点，17px / 1.9；列表项间距 8px。

### 结论强调

默认使用背景 `soft` 加左侧 3px `emphasis` 强调线，或使用白底上下 `strong_border` 细线。不要同时叠加两种方式，不输出双空线或没有内容的分隔区。

### CTA

标签使用 15px / 1.6 / 700 和 `label`。按钮容器为横向 flex；按钮至少 42px 高、4px 圆角、14px / 700。第一个按钮用 `cta` 实心，第二个用背景色和 `cta` 描边。窄屏文案过长时改为纵向，不缩小到 12px 以下。

### 来源参考

来源区使用顶部 1px `border` 分隔线。标题 26px / 1.4 / 700 / `heading`。采用论文式编号时，每条参考文献使用稳定的两列结构，不使用负首行缩进：

- 条目容器使用 `display:flex;align-items:flex-start;width:100%;max-width:100%`，不得设置负 `text-indent`。
- 编号列使用 `display:block;flex:0 0 48px;min-width:48px`，统一承载 `[1]`、`[10]` 等编号。
- 正文列使用 `display:block;flex:1 1 auto;min-width:0;max-width:100%`。续行自然回到正文列起点，与首行正文左边缘对齐，不回到编号列，也不产生额外首行缩进。
- 正文列使用 `text-align:justify;text-align-last:left;text-justify:inter-ideograph`；最后一行保持左对齐，避免短行被强行拉伸。
- 每条来源显示可读标题，完整链接保留在 `href`。域名或短来源说明使用 `url`，并设置 `white-space:nowrap;word-break:keep-all;overflow-wrap:normal`，允许整体换到下一行，但不得拆成单个字符。
- 参考文献较短时也保持相同两列结构，不能针对单条切换回普通段落或悬挂缩进。

## 推演与排版选择

- 宿主模板控制正文宽度，因此正文片段不固定宽度；完整网页预览才建议约 680px 阅读宽度。
- 参考页中的自动关键词链接不复制；只有输入已有或用户确认的链接才保留。
- 图片内容本身可能含圆角，但 `<img>` 元素不自动加圆角。
- 章节数量取决于内容，不固定为 5 个。
- 配色变化服务于内容区分，不改变事实、链接、图片或章节顺序。

## 验收清单

- 已记录配色名称与 ID，且正文只出现该方案的令牌值。
- 正文字号不小于 16px，移动端无横向滚动，正文左右不增加额外空白。
- 有明确主线的文章已对核心概念、关键节点或业务价值进行短语级强调；强调色来自当前配色，密度克制，没有整段变色或参考文献误标。
- 章节编号连续，标题与编号配对。
- 图片 100% 宽度、自动高度、具有准确 `alt`，前后没有异常大空白；每张图片都有非空图注，且“图 N”从 1 开始连续编号。
- 参考文献编号列宽一致；所有续行与首行正文左边缘对齐；不存在负 `text-indent`，域名没有被拆成单个字符。
- CTA 链接真实，来源可追溯，没有长裸链接、虚构 URL、图片或引用。
- HTML 无脚本、表单、iframe、事件属性、平台外壳、本地路径和未替换占位符。
